# Linux domain

Experimental guidance; no product/version certification. Applies with [module contract](../../../spec/modules.md).

## Applicability

Select when verified resource capabilities include linux. Record the exact resource and management boundary.

## Discovery

Record distribution, kernel, boot, packages, storage, mounts, service manager, scheduling and security boundaries. Cite sources, UTC times and unknowns.

## Safety

Preserve supported configuration ownership and recovery access before boot, storage, package or network changes. Follow the core authority, backup and writer requirements.

## Validation

Boot/service health, access, filesystem health and the requested workload outcome. Define measurable acceptance criteria before execution and record pass, fail or inconclusive evidence.

## Handover

Persist identity, ownership, dependency references, current evidence, unfinished changes, recovery location and the exact next safe action.
