# Windows domain

Experimental guidance; no product/version certification. Applies with [module contract](../../../spec/modules.md).

## Applicability

Select when verified resource capabilities include windows. Record the exact resource and management boundary.

## Discovery

Record edition/build, host or domain role, services, scheduled tasks, event logs, storage, update state and access controls. Cite sources, UTC times and unknowns.

## Safety

Distinguish local from directory-wide authority. Preserve recovery access and applicable ACLs; directory, registry, policy and reboot effects need scoped planning. Follow the core authority, backup and writer requirements.

## Validation

Affected services, event logs, access, policy effects, pending restart and workload outcome. Define measurable acceptance criteria before execution and record pass, fail or inconclusive evidence.

## Handover

Persist identity, ownership, dependency references, current evidence, unfinished changes, recovery location and the exact next safe action.
