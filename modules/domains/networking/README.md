# Networking domain

Experimental guidance; no product/version certification. Applies with [module contract](../../../spec/modules.md).

## Applicability

Select when verified resource capabilities include networking. Record the exact resource and management boundary.

## Discovery

Record device/fabric identity, management and data planes, topology, routing, DNS, firewall ownership and out-of-band access. Cite sources, UTC times and unknowns.

## Safety

Preserve an independently verified recovery path. Assess propagation, convergence and lockout risk; remote scans need scope. Follow the core authority, backup and writer requirements.

## Validation

Management access plus end-to-end data path, intended policy, convergence and rollback. Define measurable acceptance criteria before execution and record pass, fail or inconclusive evidence.

## Handover

Persist identity, ownership, dependency references, current evidence, unfinished changes, recovery location and the exact next safe action.
