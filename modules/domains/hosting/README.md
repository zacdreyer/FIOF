# Hosting domain

Experimental guidance; no product/version certification. Applies with [module contract](../../../spec/modules.md).

## Applicability

Select when verified resource capabilities include hosting. Record the exact resource and management boundary.

## Discovery

Record platform or no panel, tenancy, service ownership, supported interfaces, generated configuration, update and backup ownership. Cite sources, UTC times and unknowns.

## Safety

Detect the management layer; do not bypass generated configuration ownership. Cross-tenant changes need explicit scope. Follow the core authority, backup and writer requirements.

## Validation

Platform and tenant workload health, regeneration behaviour, isolation and recovery. Define measurable acceptance criteria before execution and record pass, fail or inconclusive evidence.

## Handover

Persist identity, ownership, dependency references, current evidence, unfinished changes, recovery location and the exact next safe action.
