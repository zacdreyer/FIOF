# Security policy

FIOF 0.1.x is experimental; no stable support commitment or platform certification is made. Publish supported release lines when releases are established.

Do not disclose exploitable issues or sensitive data publicly. Use the repository host's private vulnerability reporting feature once enabled. If unavailable, request a private channel without disclosing details. No private contact is configured in this checkout; a tested reporting channel is a [public-release prerequisite](docs/releases.md).

Reports should include version, affected contract/tool, threat scenario, sanitized reproduction and impact. Scope includes unsafe guidance, secret disclosure, path handling, authority confusion and knowledge integrity. See [threat model](docs/threat-model.md).
